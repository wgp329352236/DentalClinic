# 牙科门诊客户管理小程序（用户端）

## 项目概述

基于微信原生小程序框架开发的牙科门诊客户管理小程序用户端，支持2-3家连锁门诊的客户预约、充值、积分、推荐等核心功能。

## 技术栈

- **框架**: 微信原生小程序（TypeScript + SCSS）
- **状态管理**: 全局 `app.globalData` + 本地存储
- **API 请求**: 自定义封装（当前使用模拟数据）

## 项目结构

```
miniprogram/
├── app.json              # 全局配置（页面路由、tabBar）
├── app.ts                # 应用入口（登录状态管理）

│   ├── request.ts        # API 请求封装（含模拟数据开关）

│   ├── appointment/      # 预约页（5步流程：门诊→科室→医生→时段→确认）
│   ├── appointments/     # 预约记录页
│   ├── recharge/         # 充值页
│   ├── wallet/           # 钱包页（余额、充值记录、消费记录）

```

## 开发指南

### 切换模拟/真实数据

在 `utils/request.ts` 中修改：

```typescript
const USE_MOCK = true  // true: 使用模拟数据, false: 连接真实后端
```

### 后端接口地址

在 `utils/request.ts` 中修改 `BASE_URL`：

```typescript
const BASE_URL = 'http://localhost:8080/api/v1'
```

### 添加新页面

1. 在 `pages/` 下创建目录和4个文件（`.ts`, `.wxml`, `.scss`, `.json`）
2. 在 `app.json` 的 `pages` 数组中添加路径

### TabBar 图标

当前 tabBar 为纯文字模式。如需添加图标：

1. 准备 81x81 px PNG 图标文件到 `images/` 目录
2. 在 `app.json` 的 tabBar.list 中为每个 tab 添加 `iconPath` 和 `selectedIconPath`

参考 `images/README.md` 获取详细图标清单。

## 注意事项

1. **图片资源**: 项目中引用的图片文件（banner、头像、医生照片等）需要自行准备并放入 `images/` 目录
2. **微信登录**: 当前使用模拟 token，真实环境需在微信后台配置 AppID 并调用 `wx.login`
3. **支付功能**: 充值功能当前仅模拟成功流程，真实环境需接入微信支付 v3 API
4. **数据类型**: 所有 API 返回数据都有 TypeScript 类型定义，新增接口时请在 `types/index.ts` 中补充类型
