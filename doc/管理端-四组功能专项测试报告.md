## 五、发现的问题

### 5.1【高｜已修复】C 端领券 / 核销成功响应序列化失败（数据已写入，客户端却收到 400）

- 位置：[UserCouponRoutes.kt](file:///Users/wgp/Desktop/DentalClinic/panel/XianTong/server/src/main/kotlin/user/route/UserCouponRoutes.kt#L67-L76)（核销成功）、[同文件 L148-L158](file:///Users/wgp/Desktop/DentalClinic/panel/XianTong/server/src/main/kotlin/user/route/UserCouponRoutes.kt#L148-L158)（领取成功）、[同文件 L110-L114](file:///Users/wgp/Desktop/DentalClinic/panel/XianTong/server/src/main/kotlin/user/route/UserCouponRoutes.kt#L110-L114)（推广领券）。
- 现象：`data = mapOf("couponName" to String, "faceValue" to BigDecimal)` 推断为 `Map<String, Any>`，kotlinx 无 `Any` 序列化器 → 抛 `SerializationException` → `translateApiError` 归一成 400「请求参数格式不正确」。日志：`Serializer for class 'ApiResponse' is not found`。
- 影响：领券、核销实际成功但客户端展示失败；用户重复操作会得到「已领取/已使用」，体验与数据不一致。
- 处理：已按具名 DTO 方案修复，见第七节。

### 5.2【高｜已修复】推荐记录页接口不可用

- 位置：[UserReferralRoutes.kt](file:///Users/wgp/Desktop/DentalClinic/panel/XianTong/server/src/main/kotlin/user/route/UserReferralRoutes.kt#L95-L107)
- 现象：`data = mapOf("list" to List, "total" to Int, "summary" to DTO …)` 同样是 `Map<String, Any>`，返回 400「请求体解析失败: Serializer for class 'ApiResponse' is not found」。
- 影响：推荐页的「已邀请/奖励记录/档位」全部无法展示（推荐码与二维码正常）。
- 建议（待确认）：定义 `ReferralRecordsDto(list, total, monthlyCount, summary, tierRewards, page, pageSize)` 并直接序列化。

### 5.3【中｜已修复】门店经纬度全部为空，距离功能无数据

- 位置：`Clinics` 表 `latitude/longitude`；C 端 DTO 见 [BusinessResponse.kt](file:///Users/wgp/Desktop/DentalClinic/panel/XianTong/server/src/main/kotlin/admin/dto/response/BusinessResponse.kt#L8-L14)
