# 就诊记录搜索筛选功能说明

## 🎯 新增功能

为就诊记录列表 API 添加了强大的搜索和筛选功能，用户可以根据多种条件精确查找就诊记录。

---

## 📋 API 接口

### 增强版就诊记录列表查询

**接口**: `GET /api/v1/medical-records`

**新增查询参数**:

| 参数 | 类型 | 必填 | 说明 | 示例 |
|-----|------|------|------|------|
| page | Integer | 否 | 页码，默认 1 | `page=1` |
| pageSize | Integer | 否 | 每页数量，默认 20 | `pageSize=10` |
| startDate | String | 否 | 开始日期（yyyy-MM-dd） | `startDate=2026-01-01` |
| endDate | String | 否 | 结束日期（yyyy-MM-dd） | `endDate=2026-12-31` |
| doctorId | Long | 否 | 医生 ID | `doctorId=1` |
| departmentId | Long | 否 | 科室 ID | `departmentId=1` |
| keyword | String | 否 | 关键词搜索（诊断、备注、诊所名、医生名） | `keyword=龋齿` |

---

## 🔍 使用示例

### 示例1: 按日期范围筛选

查询 2026年9月的就诊记录：

```bash
curl -X GET "http://localhost:8080/api/v1/medical-records?page=1&pageSize=20&startDate=2026-09-01&endDate=2026-09-30" \
  -H "Authorization: Bearer <user_token>"
```

**响应**:
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "list": [
      {
        "id": 8,
        "appointmentDate": "2026-09-05",
        "clinicName": "阳光口腔门诊",
        "doctorName": "张医生",
        "diagnosis": "龋齿补牙",
        "consumptionAmount": 500.0
      }
    ],
    "total": 1,
    "page": 1,
    "pageSize": 20
  }
}
```

### 示例4: 关键词搜索

搜索包含"龋齿"的就诊记录（会搜索诊断、备注、诊所名、医生名）：

```bash

  -H "Authorization: Bearer <user_token>"
```

**搜索范围**:
- ✅ 诊断结果 (diagnosis)
- ✅ 备注 (remark)
- ✅ 诊所名称 (clinic name)
- ✅ 医生姓名 (doctor name)

## 🔧 技术实现

### Service 层改进

**MedicalRecordService.kt**:
```kotlin
suspend fun getMedicalRecords(
    userId: Long,
    page: Int,
    pageSize: Int,
    startDate: String? = null,      // 新增
    endDate: String? = null,        // 新增
    doctorId: Long? = null,         // 新增
    departmentId: Long? = null,     // 新增
    keyword: String? = null         // 新增
): MedicalRecordsResponse
```

### 筛选逻辑

1. **日期范围筛选**: 使用 `greaterEq` 和 `lessEq` 进行数据库级过滤
2. **医生/科室筛选**: 直接 SQL WHERE 条件
3. **关键词搜索**: 内存中模糊匹配（支持中文）

### 性能优化

- 日期、医生、科室筛选在数据库层面执行，减少数据传输
- 关键词搜索在内存中执行，避免复杂的 SQL LIKE 查询
- 保持分页功能，避免一次性加载大量数据

---

## ⚠️ 注意事项

1. **所有筛选参数都是可选的**，不传则不进行该条件筛选
2. **日期格式必须为 yyyy-MM-dd**，如 `2026-09-01`
3. **关键词搜索不区分大小写**，支持中文
4. **多个筛选条件可以组合使用**，取交集
5. **分页在所有筛选条件下都有效**
