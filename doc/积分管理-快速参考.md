# 积分管理模块 - 快速参考卡

## 🎯 核心功能一览

| 功能 | 接口 | 权限 | 状态 |
|-----|------|------|------|
| 查看积分规则 | `GET /api/admin/points/rules` | `points:view` | ✅ |
| 创建积分规则 | `POST /api/admin/points/rules` | `points:manage` | ✅ |
| 更新积分规则 | `PUT /api/admin/points/rules/{id}` | `points:manage` | ✅ |
| 调整客户积分 | `PUT /api/admin/customers/{id}/points` | `customer:update` | ✅ |
| 查询积分流水 | `GET /api/admin/points/records` | `points:view` | ✅ |

---

## 🔑 关键参数速查

### 积分规则字段
```kotlin
ruleName: String          // 规则名称（必填）
ruleType: String          // earn(获得) / spend(消耗)
actionType: String        // signup/consumption/profile_complete/referral等
pointsPerUnit: Int        // 每单位积分（必填，>0）
unitDescription: String?  // 单位说明（如"每消费1元"）
dailyLimit: Int?          // 每日上限
monthlyLimit: Int?        // 每月上限
validityMonths: Int       // 有效期月数（默认12）
status: Int               // 1=启用 0=停用
```

### 积分调整请求
```json
{
  "amount": 100,           // 正数=增加，负数=扣减
  "reason": "活动补偿"     // 调整原因（必填）
}
```

### 积分流水筛选参数
```
userId=123                 // 用户ID
sourceType=checkin         // 来源类型
startDate=2026-09-01       // 开始日期
endDate=2026-09-30         // 结束日期
page=1                     // 页码
pageSize=20                // 每页数量
```

## 🐛 常见问题

**Q: 编译错误 "Unresolved reference 'adminPrincipal'"**
A: 确保在 BusinessRoutes.kt 中导入了 `com.dentalclinic.admin.auth.adminPrincipal`

**Q: 编译错误 "Unresolved reference 'greaterEq'"**
A: 确保在 AdminPointsService.kt 中导入了 `org.jetbrains.exposed.v1.core.greaterEq` 和 `lessEq`

**Q: 积分调整后余额未更新**
A: 检查是否同时更新了 PointsRecords 和 UserPointsSummary 两张表

**Q: 扣减积分时报"余额不足"**
A: 系统会校验扣减后余额不能为负，请确认当前余额足够
