## 🎯 功能设计

### 1. 二维码生成方案

**方案**: 前端生成二维码（推荐）
- 后端提供优惠券详情接口，返回 `qrData` 字段
- `qrData` 格式: `{couponCode}|{userId}|{couponId}`
- 前端使用二维码库（如 qrcode.js）生成二维码图片

**优势**:
- 无需在后端引入二维码生成库
- 前端可自定义二维码样式
- 性能更好

---

### 2. 用户端 API

#### GET /api/v1/coupons/{id}/detail

**用途**: 获取优惠券详情（用于生成二维码）

**请求**:
```bash
GET /api/v1/coupons/13/detail
Authorization: Bearer <user_token>
```

**响应**:
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 13,
    "couponCode": "ADM74943863475",
    "templateName": "国庆节特惠券",
    "couponType": "cash",
    "faceValue": 200.0,
    "minConsumption": 500.0,
    "validFrom": "2026-10-01 00:00:00",
    "validTo": "2026-10-07 23:59:59",
    "status": "unused",
    "qrData": "ADM74943863475|55|13"
  }
}
```

**前端使用**:
```javascript
// 使用 qrcode.js 生成二维码
import QRCode from 'qrcode';

const qrData = response.data.qrData; // "ADM74943863475|55|13"
const qrImage = await QRCode.toDataURL(qrData);
// 显示 qrImage 在页面上
```

---

### 3. 管理端扫码核销 API

#### POST /api/admin/coupons/scan-redeem

**用途**: 扫描用户优惠券二维码并核销

**权限**: `coupon:manage`

**请求**:
```bash
POST /api/admin/coupons/scan-redeem
Authorization: Bearer <admin_token>
Content-Type: application/json

{
  "qrData": "ADM74943863475|55|13"
}
```

**成功响应**:
```json
{
  "code": 0,
  "message": "核销成功",
  "data": {
    "couponName": "国庆节特惠券",
    "faceValue": 200.0
  }
}
```

**错误响应**:
```json
{
  "code": 400,
  "message": "优惠券已使用或已过期",
  "data": null
}
```

## 🔐 安全机制

### 二维码数据格式
```
{couponCode}|{userId}|{couponId}
```

示例: `ADM74943863475|55|13`

### 核销验证流程
1. 解析 QR 数据，提取 couponCode、userId、couponId
2. 验证三者匹配（防止篡改）
3. 检查优惠券状态（必须为 unused）
4. 检查有效期
5. 标记为 used，更新 usedAt 时间
6. 更新模板的 usedQuantity

## 📱 前端实现建议

### 用户端（小程序）

```vue
<template>
  <view class="coupon-detail">
    <!-- 优惠券信息 -->
    <view class="coupon-info">
      <text>{{ coupon.templateName }}</text>
      <text>¥{{ coupon.faceValue }}</text>
    </view>
    
    <!-- 二维码 -->
    <canvas id="qrcode-canvas" />
  </view>
</template>

<script>
import QRCode from 'weapp-qrcode';

export default {
  async onLoad(options) {
    // 获取优惠券详情
    const res = await wx.request({
      url: '/api/v1/coupons/' + options.id + '/detail',
      header: { Authorization: 'Bearer ' + token }
    });
    
    this.coupon = res.data.data;
    
    // 生成二维码
    new QRCode('qrcode-canvas', {
      text: this.coupon.qrData,
      width: 200,
      height: 200
    });
  }
}
</script>
```

### 管理端（后台）

```vue
<template>
  <div>
    <!-- 扫码按钮 -->
    <button @click="startScan">扫码核销</button>
    
    <!-- 扫码结果 -->
    <div v-if="scanResult">
      <p>优惠券: {{ scanResult.couponName }}</p>
      <p>面额: ¥{{ scanResult.faceValue }}</p>
    </div>
  </div>
</template>

<script>
import QrcodeScanner from 'vue-qrcode-reader';

export default {
  methods: {
    async onDecode(qrData) {
      // 调用后端核销接口
      const res = await axios.post('/api/admin/coupons/scan-redeem', {
        qrData: qrData
      }, {
        headers: { Authorization: 'Bearer ' + adminToken }
      });
      
      this.scanResult = res.data.data;
      alert('核销成功！');
    }
  }
}
</script>
```
