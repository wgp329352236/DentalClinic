## 八、测试建议

### 1. 用户认证测试
- 使用任意用户的 openid 进行登录测试
- 用户1-10都有完整的手机号，可测试资料更新

### 2. 钱包充值测试
- 用户1当前余额1500元，适合测试充值
- 用户4余额5000元，可测试大额充值

### 3. 预约管理测试
- 查询门店列表: GET /api/v1/clinics
- 查询医生列表: GET /api/v1/doctors?clinicId=1
- 查询可预约时段: GET /api/v1/appointments/slots?doctorId=1&date=2026-09-01
- 创建预约: POST /api/v1/appointments（使用用户1）
- 取消预约: PUT /api/v1/appointments/{id}/cancel
- 改约: PUT /api/v1/appointments/{id}/reschedule

### 4. 积分测试
- 查询积分: GET /api/v1/points/balance（用户1有2600积分）
- 查询积分明细: GET /api/v1/points/records
- 兑换积分: POST /api/v1/points/redeem

### 5. 推荐裂变测试
- 获取推荐码: GET /api/v1/referral/code（用户1的推荐码是REF001）
- 绑定推荐关系: POST /api/v1/referral/bind（使用新用户ID如11，推荐码REF001）
- 查询推荐统计: GET /api/v1/referral/stats

### 6. 优惠券测试
- 查询我的优惠券: GET /api/v1/coupons/my
- 核销优惠券: POST /api/v1/coupons/{code}/use

### 7. 消息通知测试
- 查询消息列表: GET /api/v1/notifications（用户1有3条，1条未读）
- 标记已读: PUT /api/v1/notifications/{id}/read
- 批量标记已读: PUT /api/v1/notifications/read-all

### 8. 文件上传测试
- 上传文件: POST /upload
- 查看文件: GET /{fileName}
- 删除文件: DELETE /{fileName}

## 九、快速SQL查询

```sql
-- 查看所有用户及其钱包
SELECT u.id, u.nickname, u.phone, w.balance, w.bonus_balance 
FROM "user" u 
LEFT JOIN user_wallet w ON u.id = w.user_id 
WHERE u.id <= 10;

-- 查看推荐关系
SELECT r.id, u1.nickname as referrer, u2.nickname as referee, r.referral_code, r.reward_status 
FROM referral_relation r 
JOIN "user" u1 ON r.referrer_id = u1.id 
JOIN "user" u2 ON r.referee_id = u2.id;

-- 查看用户优惠券
SELECT uc.coupon_code, ct.name, uc.status 
FROM user_coupon uc 
JOIN coupon_template ct ON uc.template_id = ct.id 
WHERE uc.user_id = 1;

-- 查看用户消息
SELECT id, title, msg_type, is_read, created_at 
FROM notification 
WHERE user_id = 1 
ORDER BY created_at DESC;
```
